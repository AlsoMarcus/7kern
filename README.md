**7Kern (kernel)**
- Higher-half x86_64 kernel booted by Limine (BIOS and UEFI)
- GDT/TSS (separate double-fault stack), IDT, 8259 PIC, PIT timer
- Physical page allocator (bitmap), page-table mapping for MMIO, kernel heap
- Drivers: PS/2 keyboard + mouse (scroll wheel), VMware/QEMU absolute pointer,
  CMOS clock, PCI bus scan, storage identification (IDE/ATAPI, SATA/AHCI, NVMe, virtio-blk),
  ACPI (power off + reset), SMBIOS (device model, firmware, installed RAM), serial log
- In-memory file system with `/proc` (cpuinfo, meminfo, uptime, version)
- Panic screen with registers; press any key to restart

```

`kernel/assets.c` (fonts and icons) is generated by `tools/gen_assets.py`; it is included
so the fonts don't need to be installed to build.

## Source layout

| File | Purpose |
| --- | --- |
| `kernel/main.c` | Boot entry (`kmain`), Limine requests, boot sequence, panic screen |
| `kernel/arch.c`, `isr.asm` | GDT/TSS, IDT, PIC, PIT, CPUID |
| `kernel/mm.c` | Physical memory, page mapping, heap |
| `kernel/ps2.c` | Keyboard, mouse, absolute pointer, input event queue |
| `kernel/pci.c`, `storage.c` | PCI scan, IDE/AHCI/NVMe/virtio drive detection |
| `kernel/acpi.c`, `rtc.c` | ACPI power, SMBIOS, clock |
| `kernel/ramfs.c` | In-memory file system and `/proc` |
| `kernel/gfx.c` | Shapes, anti-aliasing, shadows, text |
